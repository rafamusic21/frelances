# El bautismo: un paso de fe

Página informativa sobre el bautismo, en formato de historieta vertical (webtoon), pensada para celulares.

## Estructura

```
index.html      → contenido de la página (viñetas, versículos, preguntas)
css/styles.css  → diseño, colores, modo oscuro y animaciones
js/script.js    → personajes en SVG, aparición de viñetas, medidor de agua y botón "Sumergir"
```

## Antes de publicar

Edita `index.html` y cambia:

1. `[Nombre de tu iglesia]` (portada y pie de página).
2. `[Fecha] en [Lugar]` del próximo bautismo.
3. El enlace `https://wa.me/` por el número del pastor, por ejemplo `https://wa.me/5215512345678`.

## Publicar con GitHub Pages

1. Sube estos archivos a la raíz de tu repositorio.
2. En GitHub ve a **Settings → Pages**.
3. En **Source** elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. En unos minutos tu página estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
